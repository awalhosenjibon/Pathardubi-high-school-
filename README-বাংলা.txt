পাথরডুবি উচ্চ বিদ্যালয় — ওয়েবসাইটের প্রাথমিক ফাইল

ফাইল:
- index.html : ওয়েবসাইটের কাঠামো
- style.css : নীল-সাদা ডিজাইন
- content.js : নোটিশের তালিকা; নতুন নোটিশ যোগ করতে এখানে সম্পাদনা করো
- assets/logo-placeholder.svg : পরে আসল লোগো দিয়ে বদলাবে
- assets/school-placeholder.svg : বিদ্যালয়ের ছবি না আসা পর্যন্ত নমুনা

মোবাইলে পরীক্ষা:
1. ফাইলগুলো আনজিপ করো।
2. index.html ব্রাউজারে খোলো (Acode-এর Preview-ও ব্যবহার করতে পারো)।
3. নোটিশ বদলাতে content.js সম্পাদনা করো।
4. ছবি বদলাতে assets ফোল্ডারে নতুন ছবি রাখো এবং index.html-এ ছবির ফাইলের নাম বদলাও।

গুরুত্বপূর্ণ:
এটি একটি সামনের অংশের (front-end) নমুনা। এখনো অনলাইন Admin Panel নেই।
পাবলিক করার আগে বিদ্যালয় কর্তৃপক্ষের অনুমতি নিয়ে সঠিক ঠিকানা, ফোন, EIIN, শিক্ষক-শিক্ষার্থী ও নোটিশের তথ্য বসাবে।
